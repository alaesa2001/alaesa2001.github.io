## Local development

Requirements: Node.js 22.13 or newer.

```bash
npm install
npm run dev
```

Then open the local URL displayed in the terminal.

## Validation and production builds

```bash
npm run lint
npm test
npm run build:vercel
```

`npm test` builds the Sites version and verifies the rendered portfolio pages, multilingual metadata, sitemap, robots rules, manifest, and core public assets.

## Engineering blog

The blog contains 100 original article pages dated from January 2022 through August 2026. Topics cover backend engineering, AWS and cloud, DevOps, architecture, data, security, frontend product work, bioinformatics, AI automation, and engineering leadership. Editorial images are stored locally for predictable performance. Every post has a canonical URL, article-specific metadata and structured data, appears in the XML sitemap, and is published through the RSS feed.
